Curve playground

Move any setting and the chart shows the day it makes, exactly as it appears on your dashboard. Four phases, not one curve explains what each phase is for.

The chart's height is brightness and its colour is the colour temperature at that moment. The vertical line is "now" — drag Time of day to move it.

Time of day

Moves the "now" marker. Nothing about the schedule changes — this is just where you're standing in the day.

Schedule

When each phase begins. Every one of these is a time entity on the schedule you add in Home Assistant — except sunset, which comes from sun.sun.

Brightness

Each phase's brightness. Evening's is a starting point rather than a hold: it fades toward Night's value over the run-up to Night Start.

Colour temperature

Each phase holds its own colour and eases to the next one over that phase's transition, below.

Transitions

How long before each phase ends to start easing toward the next one — so the new phase's values have arrived exactly as it begins. Set one to zero for a deliberate, visible change at that boundary. Anything longer than the phase it runs in simply covers the whole phase, which is why Day's colour transition defaults to a full day: it slides from Morning's colour to Evening's across the entire afternoon.

Load a schedule

Paste a schedule copied from Home Assistant (its Copy button on the schedule dashboard, or the schedule's Reconfigure) to see its curve here. Copy schedule above goes the other way: paste the result into Home Assistant to use these settings. Anything a schedule leaves out keeps its value here.
