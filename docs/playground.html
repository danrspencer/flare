Curve playground

Change any setting to see the day it gives, drawn as it appears on your dashboard. Four phases explains what each phase is for.

The chart's height is brightness and its colour is the colour temperature at that time. The vertical line is the current time; move it with Time of day.

Time of day

Moves the current-time line. It doesn't change the schedule.

Schedule

When each phase starts. In Home Assistant each is a time entity on the schedule, apart from sunset, which comes from sun.sun.

Brightness

Each phase's brightness. Evening's brightness fades towards Night's in the time before Night starts.

Colour temperature

Each phase's colour temperature. It changes to the next phase's over that phase's transition, below.

Transitions

How long before each phase ends to start changing to the next one, so the next phase's values are reached as it starts. Zero switches at the boundary. A transition longer than its phase covers the whole phase: Day's colour transition defaults to a full day, so Day's colour changes all afternoon.

Load a schedule

Paste a schedule copied from Home Assistant, with Copy on the dashboard or the schedule's Reconfigure, to see its curve here. Copy schedule, above, copies these settings to paste into Home Assistant. Settings a pasted schedule leaves out keep their values here.
